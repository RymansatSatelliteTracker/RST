# 要求内容

## 概要

無線機の制御について、YaesuのCATに対応する。
FT991のCAT使用は https://www.yaesu.com/jp/manuals/yaesu_m/FT-991_CAT_OM_J.pdf です。
（マニュアルはこのフォルダの `FT-991_CAT_OM_J.pdf`、`ft-897d_j.pdf` に保存済み。）

## 現状（コード調査結果）

- 無線機制御は `src/main/service/transceiver/controller/` 配下に集約されている。
  - `TransceiverControllerBase`：周波数／モード／サテライトモード設定とコールバックの抽象基底
  - `TransceiverSerialControllerBase`：シリアル接続の共通処理
  - `TransceiverIcomController`（＋`TransceiverIcomCmdMaker` / `TransceiverIcomRecvParser` / `TransceiverIcomState`）：ICOM(CI-V)実装
  - `TransceiverControllerFactory`：メーカーIDでコントローラを選択。YAESU分岐は**コメントアウト済み**
- `Constant.Transceiver.MakerId.YAESU = "2"` は定義済み。機種IDは `ICOM_IC910 = "4"` のみ。
- ICOM実装はメイン/サブバンド切替（サテライトモード）、トランシーブ受信によるドップラー補正一時停止、トーン設定を備える。

## 確定事項（ブレストの結果）

### 対応機種
- 今回の実装対象は **FT-991 / FT-991A** および **FT-897 / FT-897D**。
- ただし FTM / FT-8xx 系など他のYaesu機種を後から追加しやすい構造（機種差をコマンド生成・応答解析層に閉じ込める）で設計する。
- **CATの体系が機種で大きく異なる**ため、機種ごとにCmdMaker / RecvParserを分ける。
  - FT-991：ASCIIコマンド（`FA;` `MD0;` など、`;`終端）。AIによる自動通知あり。
  - FT-897：5バイトのバイナリコマンド（末尾1バイトがオペコード）。応答は固定長で、自動通知（AI相当）なし。
- FT-897の仕様は公式マニュアル（`ft-897d_j.pdf` のp.56〜57「CAT運用」「コマンド一覧表」）で確認済み。要点は下記「FT-897のCAT仕様（マニュアル確認結果）」を参照。

### Tx/Rxの扱い（サテライト運用）
- FT-991はICOMのようなメイン/サブ同時受信のサテライトモードを持たないため、**VFO-A = Rx（ダウンリンク）／VFO-B = Tx（アップリンク）＋スプリット運用**とする。
- RSTのアップリンク／ダウンリンク周波数・モードの両方を制御対象とする。
- ICOMの「メイン/サブ切替」「バンド入れ替え」に相当する処理は、VFO-A/B・スプリット制御に置き換える。

#### FT-897の場合（FT-991との差分）
- VFO-A/Bの周波数を独立に読み書きするコマンドがなく、現在表示中のVFOの周波数・モード設定／読み出しのみ。Tx/Rxの切替はVFO切替（`81`：トグル）とスプリットON/OFF（`02`/`82`）で行う。
- スプリット時にVFO-A=Rx / VFO-B=Txとするため、VFOを切り替えながら設定する（ICOMのメイン/サブ切替に近い方式）。現在どちらのVFOかを取得するコマンドはないため、**接続時に表示中のVFOをRx VFOとみなし**、RST側で状態を保持する。起動時は`82`（SPLIT OFF）を送信して状態を確定させる。
- 無線機側のダイヤル操作は通知されない。毎周期のポーリングで周波数・モードを読み取り、変化があればICOMのトランシーブ受信と同様にドップラー補正を一時停止する。
- Tx周波数の設定にVFO切替が必要で、切替の間は受信がTx周波数に移る。そのため、**Tx周波数は前回送信値から一定以上変化したときだけ送信する**（初期値：SSB系50Hz、FM系500Hz。実機で調整）。
- 読み取った周波数が前回値から**アマチュアバンドをまたいで変化した場合は「VFOずれ」**（運用中のVFO手動切替など）とみなし、RSTへは通知しない（警告ログのみ）。

#### FT-897のCAT仕様（マニュアル確認結果）
- 通信条件：4800/9600/38400bps（メニュー`No-020 CAT/LIN/TUN`を`CAT`に設定、`No-019 CAT RATE`で速度選択）、データ長8bit、パリティなし、スタートビット1、**ストップビット2**。メニュー`No-001 EXT MENU`を`ON`にしないと`No-020`は呼び出せない。
- コマンド形式：1コマンド5バイト（DATA1〜DATA4＝パラメータ P1〜P4、DATA5＝コマンド）。LSD側から順に送信する。
- 主なコマンド（DATA5）：

  | 内容 | コマンド | パラメータ |
  | --- | --- | --- |
  | 周波数設定 | `01` | P1〜P4：BCD（10Hz桁まで。例：21.17500MHz→`02 11 75 00`） |
  | モード設定 | `07` | P1：`00`LSB／`01`USB／`02`CW／`03`CWR／`04`AM／`08`FM／`0A`DIG／`0C`PKT／`88`FMN |
  | VFO A/B切替 | `81` | トグル（現在値を取得するコマンドなし） |
  | SPLIT ON/OFF | `02`/`82` | パラメータなし |
  | PTT ON/OFF | `08`/`88` | RSTからは使用しない想定 |
  | トーン方式設定 | `0A` | P1：`2A`CTCSS ON／`4A`CTCSS ENC ON／`3A`CTCSS DEC ON／`8A`OFF（DCS系も有） |
  | トーン周波数設定 | `0B` | P1〜P2：送信用、P3〜P4：受信用（BCD、0.1Hz単位。88.5Hz→`08 85`、100.0Hz→`10 00`） |
  | 周波数・モード読み出し | `03` | 応答5バイト：DATA1〜4＝周波数（BCD）、DATA5＝モード（`06`WFMを含む） |
  | 受信ステータス読み出し | `E7` | 応答1バイト：bit7 スケルチ、bit6 CTCSS/DCS検出、bit5 FM中心ずれ、bit3〜0 Sメーター |
  | 送信ステータス読み出し | `F7` | 応答1バイト：bit7 PTT（0=送信）、bit6 HI SWR、bit5 SPLIT（0=ON）、bit3〜0 POメーター |

- 周波数・モードの読み出し（`03`）以外のセット系コマンドの応答有無はマニュアルに記載がない。実機で確認する（応答が無い場合は、設定後に`03`で読み戻して確認する方式を検討）。
- 受信データに自動通知はないため、**ポーリング間隔の設計が必要**（`03`は現在のVFOのみ。Tx側の値を読むにはVFO切替が必要）。

#### FT-991のCAT仕様（マニュアル確認結果）
参照元：`FT-991_CAT_OM_J.pdf`（p.2〜3「通信フォーマット」「CATコントロールコマンド一覧表」、p.5〜18「コマンドテーブル」）

- 通信条件：既定4800bps（4800/9600/19200/38400bps）、データ長8bit、パリティなし、スタートビット1、**ストップビット2**。メニュー：USBケーブル使用時は`031 CAT RATE`、RS-232C使用時は`029 232C RATE`。CATタイムアウトタイマーはUSB`032 CAT TOT`/RS-232C`030 232C TOT`（工場出荷時10msec）。
- コマンド形式：アルファベット2文字のコマンド＋パラメータ（数字、桁数固定）＋`;`（終端）。大文字・小文字どちらでも認識する。
- 種別：Set（設定）、Read（読み出し、パラメータなし`;`のみ）、Answer（本体からの応答）。**Setコマンドに対する応答はない**。コマンド形式の誤りや実行できない状態では、`?;` を返す。
- 主なコマンド：

  | 内容 | コマンド | 備考 |
  | --- | --- | --- |
  | VFO-A周波数 | `FA` + 9桁Hz + `;`（Set/Read/Answer） | 範囲 `000030000`〜`470000000`Hz。**範囲外の値は無効**（1200MHz帯は設定不可） |
  | VFO-B周波数 | `FB` + 9桁Hz + `;`（Set/Read/Answer） | 同上 |
  | モード | `MD0` + P2 + `;`（Set/Read/Answer） | P1=`0`（MAIN RX）のみ。**VFO-Bのモードは直接設定できない**。P2：`1`LSB／`2`USB／`3`CW-U／`4`FM／`5`AM／`6`RTTY-LSB／`7`CW-R(L)／`8`DATA-LSB／`9`RTTY-USB／`A`DATA-FM／`B`FM-N／`C`DATA-USB／`D`AM-N／`E`C4FM |
  | 送信VFO | `FT` + P1 + `;`（Set）、Answer `FT` + P2 + `;` | Set P1：`2`=VFO-Aで送信、`3`=VFO-Bで送信。Answer P2：`0`=VFO-A、`1`=VFO-B。**SPLITの専用コマンド（`ST`）はなく、`FT3;`（VFO-Bで送信）でSPLITとなる** |
  | VFO入替 | `SV;`（Set） | VFO-AとVFO-Bの内容を入れ替える（[A/B]キー動作） |
  | VFO-A→B / B→A | `AB;` / `BA;` | VFO-AをVFO-Bへコピー／VFO-BをVFO-Aへコピー |
  | CTCSS方式 | `CT0` + P2 + `;`（Set/Read/Answer） | P2：`0`OFF／`1`ENC/DEC／`2`ENC／`3`DCS ENC/DEC／`4`DCS ENC |
  | CTCSSトーン番号 | `CN0` + P2 + P3(3桁) + `;`（Set/Read/Answer） | P2：`0`=CTCSS、`1`=DCS。P3：CTCSSは`000`〜`049`（表1。`Constant.Transceiver.ToneFrequency`と同じ50種・同じ並び）。**周波数ではなく番号で指定する** |
  | AI | `AI` + P1 + `;`（Set/Read/Answer） | P1：`0`OFF／`1`ON。ONにすると、無線機の状態が変化したとき、AIの対象コマンドをPCへ自動送出する。電源を切るとOFFになる |
  | 情報（VFO-A） | `IF;`（Read）→ Answer `IF` + P1(3)メモリCH + P2(9)周波数 + P3(5)クラリファイア + P4〜P10 + `;` | 周波数（P2）とモード（P6）を1コマンドで取得できる。Answerは全長28文字 |
  | 情報（VFO-B） | `OI;`（Read）→ Answer（`IF`と同じ形式、先頭`OI`） | VFO-Bの周波数・モードの読み出し |
  | 送信状態 | `TX;`（Read）→ Answer `TX` + P1 + `;` | P1：`0`=受信、`1`=CAT送信中、`2`=無線機本体で送信中 |

- AIの対象（一覧表の「AI」列が○）：`FA`、`FB`、`FT`、`MD`、`IF`、`OI`、`CT`、`CN` など。無線機側の操作で上記の状態が変わると、該当のコマンド形式で自動通知される。
- 識別：`ID;` → `ID0570;`（FT-991）。FT-991とFT-991Aの区別は、マニュアル上は同じコマンド体系。

##### FT-991のRx/Tx運用（確認結果を踏まえた方針）
- Rx＝VFO-A、Tx＝VFO-B、SPLIT＝`FT3;`、非SPLIT＝`FT2;`。
- Rx（VFO-A）の周波数・モードは、`FA`/`MD0`（またはIF）で直接設定・取得できる。
- **Tx（VFO-B）の周波数は`FB`で設定できる**が、**VFO-Bのモードを設定するコマンドはない**（`MD0`はMAIN RXのみ）。VFO-Bのモードを変えるには、`SV;`でVFOを入れ替え、`MD0`で設定し、再度`SV;`で戻す手順が必要（FT-897のVFO切替に近い方式）。トーン（`CT0`/`CN0`）もVFO-A側（MAIN）の設定であれば同様に入れ替えが必要（実機で確認）。
- 入れ替え中の無線機のAI通知（`FA`/`FB`/`IF`等）はRST操作に起因するものであり、無線機側のダイヤル操作と誤認しないよう除外する必要がある。
- 周波数範囲が30kHz〜470MHzのため、**1200MHz帯の衛星運用には対応できない**（設定せずに警告ログ）。

### 通信設定
- ポート／ボーレートは既存の設定画面でユーザーが選択する（既存UIを流用）。
- FT-991のCATレートはメニュー設定（4800/9600/19200/38400bps）と一致させる必要があるため、設定画面または説明に注記する。**ストップビットは2**（FT-897と同様）のため、`SerialComm`でストップビットを指定できるようにする。
- FT-897のCATレートはメニュー設定（4800/9600/38400bps）と一致させる必要がある。**ストップビットは2**。
- 現状の`SerialComm`はストップビット1固定のため、指定できるようにする。ストップビットは機種定義（`transceiver.json`の`stopBits`、省略時1）に持たせる。

### 周波数・モードの受信（無線機側操作の検知）
- FT-897はAI相当の自動通知がないため、**ポーリング**で検知する（FT-991のみ以下のAIを使用）。
- **AI（Auto Information）機能（FT-991）**（`AI1;` 等）で無線機側のダイヤル／モード操作の自動通知を受信する（通知は`FA`/`FB`/`MD`/`IF`/`OI`などの形式。RST側の処理でVFO-Aの周波数・モードのみ反映する）。
- ICOMのトランシーブ受信と同等に、無線機側で周波数を変更された場合はドップラー補正の送信を一時停止し、混線を防ぐ。
- 接続時にAIを有効化し、停止（切断）時には無効化する。
- FT-991のAIは無線機の電源を切るとOFFになり、Setコマンドには応答がない。そのため、FT-991でも**低頻度（5周期に1回）の定期読み取り（`IF;`）とAIの再送（`AI1;`）**を行い、電源の入れ直し後の復帰と、設定の反映を確認する。

### モード対応
- RSTのモードとFT-991のモードを以下のとおり対応付ける。
  - LSB↔MD01、USB↔MD02、CW↔MD03(CW-U)、FM↔MD04、AM↔MD05
  - LSB-D↔MD08(DATA-LSB)、USB-D↔MD0C(DATA-USB)、FM-D↔MD0A(DATA-FM)
- RSTに存在しないFM-N / AM-N / C4FM / RTTY系などを無線機から受信した場合の扱いは設計時に決める（近いモードへ読み替え、または無視）。
- FT-991のモードコードはマニュアルで確認済み（上記の対応が正しい）。CW-L(`7`)・RTTY-USB(`9`)・FM-N(`B`)・AM-N(`D`)・C4FM(`E`)の受信時の読み替えは設計で決める。
- FT-991のMDは`MD0`（MAIN RX）のみのため、Tx側（VFO-B）のモード設定にはVFO入替（`SV;`）を使う（上記「FT-991のRx/Tx運用」）。
- FT-897のモード対応：LSB↔00、USB↔01、CW↔02、AM↔04、FM↔08。
- FT-897にはDATA-USB/DATA-LSB/DATA-FMの区別がなく、デジタル系はDIG(`0A`)/PKT(`0C`)で表現される。CWR(`03`)、WFM(`06`)、FMN(`88`)の扱いは設計で決める。
- **（承認済み）** USB-D/LSB-D→DIG(`0A`)、FM-D→PKT(`0C`)。DIGの側波帯は無線機のメニュー`No-038 DIG MODE`（`-L`/`-U`）で決まりCATでは指定できないため、ユーザーが事前に設定する。DIG受信時は、RSTが直前に要求したLSB-D/USB-Dを維持し、無ければUSB-Dとする。詳細は `2_design.md` §5.1 を参照。

### トーン（CTCSS）
- ICOM同様、Tx側のCTCSSトーン設定に対応する（FT-991：`CT0`のP2=`2`（CTCSS ENC）と、`CN0`でトーン**番号**（`000`〜`049`）を設定する。AutoOff時は`CT0`のP2=`0`（OFF））。
- FT-897：トーン方式`0A`（P1=`4A`でCTCSS ENC ON、`8A`でOFF）と、トーン周波数`0B`（BCD、0.1Hz単位）で設定する。Tx VFOに切り替えて設定する。
- AutoOff時にトーンを解除する。

### 設定画面（UI）
- メーカー選択の YAESU の機種リストに FT-991 / FT-991A、FT-897 / FT-897D を追加し、未対応の FT-847 を削除する（ユーザー確認済み）。
- CI-Vアドレス入力欄は **ICOM選択時のみ表示**する。
- 機種IDを `Constant.Transceiver.TransceiverId` に追加する。
- 無線機側のメニュー設定（CATレート、FT-897のDIG MODE・PKT RATE等）の注記を、選択中の機種に応じて設定画面に表示する（I18nMsgsに日英で追加）。
- **運用モード選択肢の機種別表示**：衛星設定・メイン画面の運用モード選択肢を、選択中の無線機に応じて絞り込み、表示ラベルを切り替える。
  - 衛星設定への保存値は変更せず（`USB-D` など）、選択肢と表示ラベルのみ変更する（既存データの移行は不要）。
  - 機種定義（`transceiver.json`）に `supportedModes`（使えるモード）と `modeLabels`（表示ラベル）を持たせる。
  - 表示例（FT-897）：一覧は `USB-D(DIG)` / `LSB-D(DIG)` / `FM-D(PKT)`、選択後の表示は `USB-D`。RTTY・DVは選択肢に出さない。ICOMは現状どおり。
  - DIGの側波帯が無線機のメニューに依存する点は、表示では解決できないため、設定画面の注記で案内する。

## 想定される実装範囲

2フェーズで実施する（詳細は `2_design.md`、`3_tasklist.md`）。

- **フェーズ1：現状のリファクタリング**
  - ICOMの特性テスト（実機なし）を先に作成し、ICOMの挙動を固定する。
  - ICOMコントローラから、ロック（`TransceiverLock`）と待機タイマー（`TransceiverWaitTimer`）を部品として切り出す。通知系のヘルパーを基底クラスへ引き上げる。
  - `SerialComm` でストップビットを指定できるようにする。
- **フェーズ2：CAT対応**
  - 追加：`controller/yaesu/` 配下に、機種共通の `TransceiverYaesuController` / `TransceiverYaesuState` / `TransceiverYaesuSerialIo` / `TransceiverYaesuProtocol`、機種別の Protocol / CmdMaker / RecvParser（FT-991用ASCII、FT-897用バイナリ）。
  - 変更：`TransceiverControllerFactory`（YAESU分岐の有効化）、`Constant`（機種ID）、機種定義（`transceiver.json`：機種の追加・削除、`stopBits`、`supportedModes`、`modeLabels`）、接続テストのストップビット受け渡し、設定画面（CI-V欄の出し分け、機種別の注記）、運用モードの選択肢（機種別の絞り込み・表示ラベル）、`I18nMsgs`。
  - `AppConfigValidator` は変更不要（CI-Vアドレスは必須チェックがないため、YAESU選択時の空文字でも通る）。
- 更新：`/doc` 配下の設計ドキュメント

## 設計で確定した方針（レビュー結果を含む）

- FT-991のSetコマンドの成否：`?;`は警告ログとし、反映の確認は定期読み取り（5周期に1回の`IF;`）で行う。
- FT-991・FT-897の周波数範囲：30kHz〜470MHz外（1200MHz帯等）は送信せず警告ログ。
- 送信中は、VFO切替・入替を伴う設定（FT-897のTx設定、FT-991のTxモード・トーン設定）を行わず、次周期に再試行する。
- VFOが運用中に切り替えられた場合：読み取り値がアマチュアバンドをまたいで変化したら「VFOずれ」として通知しない（自動修復はしない）。
- FT-897のTx周波数：前回送信値から一定以上変化したときだけ送信する。
- 起動時：FT-991は`FT2;`、FT-897は`82`を送信してSPLIT OFFに揃える。
- 機種定義の追加項目（`stopBits`等）は optional とし、使用側で既定値を補う（JSONを型変換するだけでインスタンス化されないため）。
- 既存設定の後方互換：衛星設定の保存値（モード名）は変更しない。FT-847を保存済みの旧設定は、YAESUコントローラの生成時に「未対応の機種」としてエラーになる（YAESUはこれまで接続できなかったため、実害はない想定）。
