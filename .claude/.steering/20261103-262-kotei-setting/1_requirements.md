# 要求内容

Issue: https://github.com/RymansatSatelliteTracker/RST/issues/262 （衛星設定画面に「固定モード」を追加）

## 概要

- 衛星設定画面（衛星情報編集ダイアログ）に「固定モード」の項目を追加する。選択肢は「衛星固定」「送信固定」「受信固定」。デフォルトは「衛星固定」とする。
- 無線機のAutoOn時に、メイン画面のドップラーシフトモード（衛星固定/受信固定/送信固定）の初期値として、衛星設定画面で設定した固定モードを設定する。

## 背景

- 現状、メイン画面の固定モード（`DopplerShiftModeSelect`）は、衛星ごとの設定を持たず、ユーザーが手動で切り替える（`useTransceiverCtrl.ts` の `dopplerShiftMode`、初期値は衛星固定）。
- SatPC32では、FM衛星（ISS、SO-50など）は強制的に衛星固定となり、受信固定／送信固定は選択できない。リニア衛星を選択すると、初期設定した受信固定／送信固定に戻る。
- FT4運用は衛星固定が望ましいが、モードはSSB（LSB/USB）で運用するため、通常のCW/SSBと区別できず、人が衛星固定に設定する必要がある。
- 衛星ごとに固定モードを保持できれば、衛星を切り替えるたびに手動で固定モードを変更する必要がなくなり、誤った運用を避けられる。

## 画面イメージ

添付画像（衛星情報編集ダイアログ。RS-44の例）の「サテライトモード」行の下に、「固定モード」行を追加する。

```
  サテライトモード   [ ] 有効   (o) ノーマル  ( ) リバース
  固定モード         (o) 衛星固定   ( ) 送信固定   ( ) 受信固定
  概要
```

- 項目名は「固定モード」（画像では左端が切れて「定モード」と見えるが、「固定モード」と解釈する）。
- ラジオボタン3択（衛星固定 / 送信固定 / 受信固定）。
- 並び順は画像どおり「衛星固定 → 送信固定 → 受信固定」とする（確定）。メイン画面のセレクトボックスの並び（衛星固定 → 受信固定 → 送信固定）とは異なるが、そのままとする。
- サテライトモードの有効/無効に関わらず、常に活性とする（確定）。

## 要求仕様

### 要求A: 衛星設定への固定モード項目の追加

1. 衛星情報編集ダイアログに「固定モード」ラジオボタン（衛星固定/送信固定/受信固定）を追加する。
2. 新規の衛星、および固定モードが未設定の既存データは「衛星固定」として扱う。デフォルト衛星定義（`frequency.json`）の既存衛星は個別設定せず、すべて衛星固定とする（確定）。
3. 固定モードは衛星ごとに保存する。
   - デフォルト衛星定義（`DefaultSatelliteType`、`frequency.json`）
   - アプリケーション設定の対象衛星（`AppConfigSatellite`）
4. 既存の保存データ（固定モード項目を持たないもの）を読み込んでも不具合なく動作し、「衛星固定」として扱う。
5. ダイアログのOK/キャンセル/リセットの挙動は、他の項目と同様とする。
   - リセットはダイアログを開いた時点の値に戻す。
   - 固定モードを変更した場合も「マニュアル設定」状態になる。
6. 画面表示は多言語対応（I18n）とする。ラベルは既存の `G2_FIXED_SAT / G2_FIXED_RX / G2_FIXED_TX` を再利用するか、衛星設定用に追加するかを設計時に決める。

### 要求B: AutoOn時の初期値反映

1. 無線機のAutoOn開始時（`TransceiverModeCoordinator.startAutoMode`）に、アクティブ衛星の固定モードをメイン画面のドップラーシフトモード（`dopplerShiftMode`）へ設定する。
2. AutoOn状態でアクティブ衛星を切り替えた場合も、新しい衛星の固定モードを設定する（Autoモードが再開始されるため、`startAutoMode` で設定される）。
3. AutoOff状態でアクティブ衛星を切り替えた場合は、メイン画面の固定モードを変更しない（確定）。
4. AutoOn中に衛星設定画面でアクティブ衛星の固定モードを変更した場合は、実行中の追尾へは即時反映せず、次回のAutoOn開始時または衛星切替時に反映する（確定）。
5. AutoOn後にメイン画面で固定モードを手動変更することは、従来どおり可能とする。この変更は衛星設定には保存せず、次回のAutoOn時に衛星設定の値で上書きされる。
6. 固定モードの値を渡す経路として、`ActiveSatServiceHub.getActiveSatTransceiverSetting()` の戻り値に固定モードを追加する方向で検討する（`satTrackMode` と同様の扱い）。

### 要求C: 既存仕様との整合

1. 固定モード「衛星固定」を設定した衛星のAutoOn動作は、現状（デフォルトの衛星固定）と同一であること。
2. 受信固定／送信固定の周波数算出ロジック（`TransceiverDopplerModeResolver`、`TransceiverFreqCoordinator`、`TransceiverDopplerCalc`）は変更しない。
3. 衛星設定画面の既存項目（周波数、モード、トーン、サテライトモード、概要）の挙動は変更しない。

## 確認事項の結果

| # | 確認事項                         | 結果                                                                         |
| - | -------------------------------- | ---------------------------------------------------------------------------- |
| 1 | 固定モードラジオの活性条件       | サテライトモードの有効/無効に関わらず、常に活性                              |
| 2 | FM衛星の強制衛星固定             | スコープ外（概要に記載の内容のみ対応）                                       |
| 3 | ラジオボタンの並び順             | 衛星固定 → 送信固定 → 受信固定（画像どおり）                                 |
| 4 | AutoOn中の衛星設定変更の反映     | 次回のAutoOn開始時または衛星切替時に反映                                     |
| 5 | `frequency.json` の既存衛星      | すべて衛星固定（個別設定なし）                                               |
| 6 | AutoOff時の衛星切替              | メイン画面の固定モードは変更しない（AutoOn開始時、AutoOn中の衛星切替時のみ設定） |

## スコープ外（Non-Goals）

- 受信固定／送信固定のドップラー補正ロジックの変更（別Issue: 20261103-doppler-fixed-drift で対応）。
- FM衛星で強制的に衛星固定とする機能。
- メイン画面で手動変更した固定モードを衛星設定へ自動保存する機能。
