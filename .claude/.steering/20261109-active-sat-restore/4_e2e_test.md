# E2Eテスト：再起動時のアクティブ衛星の不一致修正

要求は [`1_requirements.md`](./1_requirements.md)、設計は [`2_design.md`](./2_design.md) を参照。

## 1. 方針

- 再起動後の状態を左右するのは、保存された AppConfig（`mainDisplay.activeSatelliteId`）だけである。
- そのため「2つ目の衛星で終了 → 再起動」は、「アクティブ衛星＝2つ目」と保存した AppConfig でアプリを起動することで再現する（fixture の `testData` で指定）。
- 修正B（通知の取りこぼし・並行実行）は処理のタイミングに依存し、E2E では安定して再現できないため、単体テスト（`ActiveSatServiceHub.test.ts`）で確認する。

## 2. テストデータ

`src/__tests__/playwright/helpers/activeSatRestoreTestData.ts`

| 並び順 | 衛星           | 軌道傾斜角 | 地図上の軌道           |
| ------ | -------------- | ---------- | ---------------------- |
| 1つ目  | E2E-EQUATORIAL | 0.1°       | 南北にほとんど振れない |
| 2つ目  | E2E-POLAR      | 98°        | 南北に大きく振れる     |

- ネットワークから取得する軌道要素に依存しないよう、ユーザ登録衛星（TLE を設定ファイルに持つ）とする。
- グループの選択肢に表示させるため、既定衛星定義にも追加する。
- TLE の生成は `e2eTestData.ts` の `makeTle()`（軌道傾斜角を指定可能。`beaconTestData.ts` から移動）を使う。

## 3. 確認方法

| 確認対象               | 確認方法                                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 衛星選択ボックス       | `.sat_select` の表示値                                                                                            |
| 保存済みアクティブ衛星 | `rstApi.getAppConfig()` の `mainDisplay.activeSatelliteId`                                                        |
| 地図の軌道             | 線の太さ 1.5 の SVG パス（OrbitLine）の外接矩形の高さ ÷ 地図の高さ。極軌道は 0.3 超、赤道軌道は 0〜0.1 未満とする |

## 4. テスト一覧（`src/__tests__/playwright/activeSatRestore.test.ts`）

| No  | 前提（保存済みアクティブ衛星） | 操作                       | 期待結果                                                                | 修正前 |
| --- | ------------------------------ | -------------------------- | ----------------------------------------------------------------------- | ------ |
| 1   | 2つ目（極軌道）                | 起動                       | 選択ボックス・地図の軌道ともに2つ目。保存済みアクティブ衛星が変わらない | 失敗   |
| 2   | 2つ目（極軌道）                | 起動 → 1つ目 → 2つ目に切替 | 切り替えのたびに、地図の軌道と保存済みアクティブ衛星が選択に追従する    | 失敗   |
| 3   | 1つ目（赤道軌道）              | 起動                       | 選択ボックス・地図の軌道ともに1つ目。保存済みアクティブ衛星が変わらない | 成功   |

- No.1・2 は、修正前のコードでは選択ボックスが1つ目（E2E-EQUATORIAL）になり失敗することを確認済み。
