# 無線機制御（YAESU）

YAESU無線機のCAT制御の仕様をまとめる。ICOM（CI-V）は対象外。

---

## 1. 対象機種

| 機種                | 機種ID | CATの体系                                                            | 無線機側の操作の検知    |
| ------------------- | ------ | -------------------------------------------------------------------- | ----------------------- |
| FT-991 / FT-991A    | `2`    | ASCIIコマンド（英字2文字＋数字＋`;`）                                | 自動通知（AI）          |
| FT-897 / FT-897D    | `3`    | 5バイトのバイナリコマンド（パラメータ4バイト＋コマンド1バイト）      | ポーリング（毎周期）    |

- 機種IDはメーカー内でのみ一意（ICOMの機種IDと重複する）ため、必ずメーカーIDと組み合わせて判定する。
- 機種定義は `resources/data/init-data/transceiver.json`（アプリ起動のたびに、ユーザー環境へ上書きコピーされる）。
- FTM、FT-8xx系など他機種は、機種別のProtocolを追加することで対応できる構造としている。

---

## 2. 構成

メインプロセスの `src/main/service/transceiver/controller/` 配下。YAESU用のファイルは `yaesu/` に置く。

```
TransceiverControllerFactory ........ メーカー、機種IDからコントローラを選択する
  TransceiverYaesuController ........ 制御の流れ（定期処理、状態管理、無線機側の操作の検知、送信の一時停止）
    TransceiverYaesuState ........... RST側の要求値、無線機側の取得値の保持、Tx周波数の送信間引きの判定
    TransceiverYaesuSerialIo ........ 送受信（1件ずつの排他制御、応答待ち、フレームの切り出し）
    TransceiverYaesuProtocol ........ 機種別のCAT制御のインターフェース
      TransceiverYaesuFt991Protocol . FT-991 / FT-991A（CmdMaker：コマンド生成、RecvParser：応答の解析）
      TransceiverYaesuFt897Protocol . FT-897 / FT-897D（CmdMaker：コマンド生成、RecvParser：応答の解析）
```

- 共通部品（`TransceiverLock`：無線機との送受信の排他、`TransceiverWaitTimer`：無線機側の操作後の送信の一時停止）は、ICOMコントローラと共用する。
- コントローラは、機種固有の手順（VFOの切り替えなど）を知らず、「Rx/Txの周波数・運用モードを設定する」「Rxを読み取る」という論理操作のみをProtocolに依頼する。

---

## 3. RSTと無線機の対応（サテライト運用）

| RST側                  | FT-991 / FT-991A                      | FT-897 / FT-897D                                       |
| ---------------------- | ------------------------------------- | ------------------------------------------------------ |
| Rx（ダウンリンク）     | VFO-A                                 | 接続時に表示されているVFO（Rx VFO）                    |
| Tx（アップリンク）     | VFO-B                                 | もう一方のVFO（Tx VFO）                                |
| サテライトモードOn     | SPLIT On（`FT3;`：VFO-Bで送信）       | SPLIT On（`02`）                                       |
| サテライトモードOff    | SPLIT Off（`FT2;`）                   | SPLIT Off（`82`）                                      |

- サテライトモードOffの場合は、無線機から受信した周波数・運用モードを、アップリンクとして通知する（ICOMと同じ）。
- 無線機側のTx周波数は読み取らない（RST→無線機の一方向）。

---

## 4. 通信条件

| 項目             | FT-991 / FT-991A                                       | FT-897 / FT-897D                                              |
| ---------------- | ------------------------------------------------------ | ------------------------------------------------------------- |
| ボーレート       | 4800（既定）/ 9600 / 19200 / 38400bps                  | 4800 / 9600 / 38400bps                                        |
| データ長         | 8bit                                                   | 8bit                                                          |
| パリティ         | なし                                                   | なし                                                          |
| ストップビット   | **2**                                                  | **2**                                                         |
| 無線機側のメニュー | `031 CAT RATE`（RS-232Cは `029 232C RATE`）          | `001 EXT MENU`＝ON、`020 CAT/LIN/TUN`＝CAT、`019 CAT RATE`    |

- ストップビットは、機種定義の `stopBits`（省略時1）で指定する。接続テストでも同じ値でシリアルを開く。
- 周波数の設定範囲は、いずれも30kHz〜470MHz（範囲外の周波数は設定せず、警告ログを出力する。1200MHz帯は設定できない）。

## 5. FT-991 / FT-991A の制御

| 論理操作                 | コマンド                                         | 備考                                                            |
| ------------------------ | ------------------------------------------------ | --------------------------------------------------------------- |
| Rx周波数の設定           | `FA` + 9桁Hz + `;`                               | VFO-A                                                           |
| Tx周波数の設定           | `FB` + 9桁Hz + `;`                               | VFO-B。受信に影響しないため、毎回送信する                       |
| Rxの周波数・モードの読み取り | `IF;`                                        | 応答28文字。周波数（P2）、モード（P6）                          |
| Rxの運用モードの設定     | `MD0` + モード + `;`                             | `MD0`はVFO-Aのみ                                                |
| Txの運用モード、トーンの設定 | `SV;`（VFO入替）→ 設定 → `SV;`（元に戻す）   | VFO-Bには直接設定できないため、VFOを入れ替えて設定する         |
| SPLIT                    | `FT3;` / `FT2;`                                  |                                                                 |
| トーン                   | `CT02;`（CTCSS ENC）、`CN00` + 3桁番号 + `;`     | 周波数ではなくトーン番号（000〜049）で指定する                  |
| 自動通知（AI）           | `AI1;` / `AI0;`                                  | 接続時にOn、切断時にOff。電源を切るとOffになる                  |
| 送信状態の読み取り       | `TX;`                                            | 0：受信、1：CAT送信中、2：本体で送信中                          |

- Setコマンドに応答はない（エラー時のみ `?;`）。
- **VFOの入れ替え**：送信中でないことを（`TX;`で）確認してから行う。入れ替え中、および解除後500msの自動通知は、RSTの操作に起因するものとして無視する。Txの運用モード、トーンが変化したときのみ行う（周波数の更新のみでは行わない）。
- **定期読み取り**：5周期に1回、`IF;`で周波数・運用モードを読み取り、`AI1;`を再送する（電源の入れ直し後のAIの復帰、設定の反映の確認のため）。Rxの設定を送った周期は、読み取らない。

## 6. FT-897 / FT-897D の制御

| 論理操作                 | コマンド（5バイト）                              | 備考                                                            |
| ------------------------ | ------------------------------------------------ | --------------------------------------------------------------- |
| 周波数の設定             | `P1 P2 P3 P4 01`                                 | 10Hz単位のBCD（上位桁から）。例：439.70MHz → `43 97 00 00 01`   |
| 運用モードの設定         | `P1 00 00 00 07`                                 | `00`LSB、`01`USB、`02`CW、`04`AM、`08`FM、`0A`DIG、`0C`PKT     |
| VFO切り替え              | `00 00 00 00 81`                                 | トグル。現在のVFOを取得するコマンドはない                       |
| SPLIT                    | `00 00 00 00 02` / `82`                          |                                                                 |
| トーン                   | `4A 00 00 00 0A`（ENC On）/ `8A ...`（Off）、`P1 P2 P3 P4 0B` | トーン周波数は0.1Hz単位のBCD                       |
| 周波数・モードの読み取り | `00 00 00 00 03`                                 | 応答5バイト。表示中のVFOの値                                    |
| 送信ステータスの読み取り | `00 00 00 00 F7`                                 | 応答1バイト。bit7＝0で送信中                                    |

- **VFOの制御**：現在表示中のVFOの周波数・モードのみ設定・取得できる。RSTは、接続時に表示されているVFOをRx VFOとみなして状態を保持する。Tx VFOの設定は、送信中でないことを確認し、Tx VFOへ切り替えて設定し、必ずRx VFOへ戻す。
- **Tx周波数の送信間引き**：Tx VFOの設定のたびに、受信が一瞬Tx周波数へ移るため、前回送信した値からの変化が一定以上（SSB・CW・DIG系：50Hz、FM系：500Hz。実機で調整）のときのみ送信する。Txの運用モードの変更時、AutoOn時は必ず送信する。
- **コマンド間隔**：50ms（実機で調整）。
- 起動時に `82`（SPLIT Off）を送信し、RSTの初期状態（サテライトモードOff）と一致させる。

## 7. 運用モードの対応

| RST         | FT-991 / FT-991A                                  | FT-897 / FT-897D                                       |
| ----------- | ------------------------------------------------- | ------------------------------------------------------ |
| LSB / USB   | `1` / `2`                                         | `00` / `01`                                            |
| CW          | `3`（受信時：CW-Rの`7`もCW）                      | `02`（受信時：CWRの`03`もCW）                          |
| AM          | `5`（受信時：AM-Nの`D`もAM）                      | `04`                                                   |
| FM          | `4`（受信時：FM-Nの`B`もFM）                      | `08`（受信時：WFM`06`、FMN`88`もFM）                   |
| RTTY        | `6`（受信時：RTTY-USBの`9`もRTTY）                | 設定不可                                               |
| LSB-D       | `8`（DATA-LSB）                                   | `0A`（DIG）                                            |
| USB-D       | `C`（DATA-USB）                                   | `0A`（DIG）                                            |
| FM-D        | `A`（DATA-FM）                                    | `0C`（PKT）                                            |
| DV          | 設定不可（受信時：C4FMの`E`をDVとして通知）       | 設定不可                                               |

- 設定画面の運用モードの選択肢は、機種定義の `supportedModes`（使えるモード）、`modeLabels`（表示ラベル。例：FT-897は「USB-D(DIG)」「FM-D(PKT)」）で、機種ごとに切り替わる。保存する値は、運用モード名のままとする。
- FT-897でDIGを受信した場合は、側波帯を判別できないため、RSTが直前に要求したLSB-Dを維持し、それ以外はUSB-Dとして扱う。

## 8. 無線機側の操作の検知

無線機のダイヤルなどで周波数・運用モードが変更された場合は、ICOMのトランシーブ受信と同様に、RSTへ通知し、レンダラ側のドップラーシフト補正を待機させ、RSTから無線機への送信を一時停止する（周波数：2秒、運用モード：5秒）。

| 機種          | 検知の方法                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------------ |
| FT-991        | 自動通知（`FA`、`MD0`、`IF`）を受信する。一時停止中は、何も送信しない（読み取りも行わない）                        |
| FT-897        | 毎周期、周波数・モードを読み取り、前回の値と比較する。一時停止中も、読み取りのみ行う                               |

- **VFOずれの判定**：読み取った周波数が、前回の値、およびRSTが直近に要求したRx周波数のいずれとも、アマチュアバンド（144 / 430 / 1200MHz帯）が異なる場合は、無線機側でVFOが切り替えられたとみなし、RSTへ通知しない（警告ログのみ）。元のVFOに戻すと、通常の動作に復帰する。
- **起動時の応答タイムアウト**：起動から2秒間、無線機から一度も受信がない場合（ボーレートの設定違い、電源Offなど）は、定期処理とシリアル接続を停止し、受信タイムアウトを通知する。

---

## 9. 制限事項

- FT-897：運用中にユーザーがVFOを手動で切り替えると、RSTのRx/Txの対応がずれる（上記のVFOずれの判定で、Rxの誤通知は防ぐが、自動では修復しない）。RSTでの運用中は、VFOを切り替えない。
- FT-897：Tx周波数は、前回送信した値から一定以上変化した場合のみ送信するため、閾値未満（SSB系50Hz、FM系500Hz）の誤差が残る。
- FT-897 / FT-991：送信中（PTT On）は、VFOの切り替え、入れ替えを伴うTx側の設定（FT-897のTx周波数・運用モード・トーン、FT-991のTx運用モード・トーン）を行わず、次周期に再試行する。
- FT-897：USB-D / LSB-D（DIG）の側波帯は、無線機のメニュー`No-038 DIG MODE`（USB-Dは`-U`、LSB-Dは`-L`）で決まり、RSTからは指定できない。FM-D（PKT）の速度は、メニュー`No-073 PKT RATE`で設定する。RTTY、DVは設定できない。
- FT-991：Tx側の運用モード・トーンの変更時に、VFOを一時的に入れ替える（数十〜数百ms）。この間、受信周波数が一時的に変わる。
- 1200MHz帯の周波数は、いずれの機種も設定できない。
