# 画面設計書 G-2 メイン画面

## 1. 画面概要

- 画面ID: G-2
- 画面名: メイン画面
- 役割:
  - 衛星追跡の主操作画面。衛星選択、AOS/LOS確認、地図・レーダ表示、無線機制御を1画面で行う。
- 主な構成:
  - 左エリア（衛星選択/AOS/時刻/地図/レーダ）
  - 右エリア（無線機制御）
  - 左サイドメニュー（各種設定ダイアログ起動）

### 2.3.2 Dopplerモード

| 項目       | 内容                                                                  |
| ---------- | ---------------------------------------------------------------------- |
| ①説明      | ドップラーシフト補正の基準（衛星固定/受信固定/送信固定）を選択する。 |
| ②種別      | セレクトボックス                                                        |
| ③表示/入力 | 入力                                                                    |
| ④表示条件  | 常時                                                                    |

⑤制御条件

- 衛星固定
  - Auto ON時にRx/Tx周波数を選択中衛星の周波数に設定し、以降Rx/Tx双方にドップラーシフト補正を適用する。
  - 無線機側のダイヤル操作でRx/Tx周波数が変化した場合も、双方ともRST側の表示・基準周波数に反映する。
- 受信固定
  - Auto ON時にRx周波数を選択中衛星の受信周波数に設定し、以降Rxにはドップラーシフト補正を適用しない（固定）。
  - Txには適用する（衛星固定と同様）。
  - 無線機側のダイヤル操作はRx側としてのみ受け付け、そのままRST側のRx表示・基準周波数に反映する（Tx側の基準周波数は基準周波数の和（Sum）を保つように再計算される）。
  - Tx側の無線機通知（ダイヤル操作に伴い無線機の内部処理でTx周波数が自動的に変化した場合を含む）は取り込まず、RST側で算出した値を常に正とする。
  - ダイヤル操作終了後、Rxにはドップラーシフト補正を適用しないため、直前のダイヤル操作で更新された基準周波数から改めてRx周波数を算出し、無線機へ送信して受信固定を継続する。
- 送信固定
  - Auto ON時にTx周波数を選択中衛星の送信周波数に設定し、以降Txにはドップラーシフト補正を適用しない（固定）。
  - Rxには適用する（衛星固定と同様）。
  - 無線機側のダイヤル操作はRx側としてのみ受け付け、そのままRST側のRx表示・基準周波数に反映する（Tx側の基準周波数は基準周波数の和（Sum）を保つように再計算される）。
  - Tx側の無線機通知（ダイヤル操作に伴い無線機の内部処理でTx周波数が自動的に変化した場合を含む）は取り込まず、RST側で算出した値を常に正とする。
  - ダイヤル操作終了後、Txにはドップラーシフト補正を適用しないため、直前のダイヤル操作で更新された基準周波数から改めてTx周波数を算出し、無線機へ送信して送信固定を継続する。
- サテライトモードOFF時は、Rx周波数はTx周波数に同期する専用の値となるため、受信固定モードにおけるダイヤル操作終了後のRx再送信処理は行わない（Rx周波数はTxに同期して送信される）。送信固定モードの動作（ダイヤル操作終了後のTx再送信、Tx側無線機通知の取り込み拒否）はサテライトモードの状態に関わらず変わらない。

## 3. イベント

### 3.1 画面・初期化イベント

| No  | 対象項目   | イベント                   | 動作                                                                          |
| --- | ---------- | -------------------------- | ----------------------------------------------------------------------------- |
| 1   | メイン画面 | 画面初期表示               | アクティブ衛星サービス起動、衛星の軌道要素データ(OMM)読込、ローテータ監視開始、無線機監視開始。 |
| 2   | メイン画面 | 周波数編集画面オープン通知 | 外部イベント受信で周波数編集ダイアログを表示する。                            |

### 3.2 メイン画面入力イベント

| No  | 対象項目                 | イベント     | 動作                                                                                     |
| --- | ------------------------ | ------------ | ---------------------------------------------------------------------------------------- |
| 1   | 衛星グループ選択         | モデル値更新 | 選択したグループIDをAppConfigへ保存し、表示対象衛星を更新する。                          |
| 2   | 衛星選択                 | モデル値更新 | 選択した衛星IDをAppConfigへ保存し、アクティブ衛星を更新する。                            |
| 3   | サイドメニュー各アイコン | クリック     | 各設定ダイアログ（衛星/無線機/ローテータ/地上局）を表示する。                            |
| 4   | 無線機制御パネル         | 日時更新通知 | Date Time変更後の基準日時をメイン画面へ通知し、地図/レーダ/AOS表示の基準時刻を同期する。 |

### 3.3 無線機制御パネル主要イベント

| No  | 対象項目       | イベント | 動作                                                  |
| --- | -------------- | -------- | ----------------------------------------------------- |
| 1   | Auto           | クリック | Autoモード開始/停止を実行し、状態をストアへ反映する。 |
| 2   | Beacon         | クリック | ビーコンモードON/OFF切替（ON時は開発中通知を表示）。  |
