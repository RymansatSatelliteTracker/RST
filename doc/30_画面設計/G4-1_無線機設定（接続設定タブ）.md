# 画面設計書 G-4-1 無線機設定ダイアログ（接続設定タブ）

## 1. 画面概要

- 画面ID: G-4-1
- 画面名: 無線機設定ダイアログ - 接続設定タブ
- 役割:
  - 無線機の機種・シリアル接続情報を設定し、接続テストを行う。
- 主な構成:
  - 左エリア（メーカー / 機種 / シリアルポート / CI-Vアドレス（ICOMのみ） / ボーレート / 機種別の案内 / 接続テスト）
  - 右エリア（IPアドレス / IPポート）

---

## 2. 画面項目

### 2.1 メーカー

| 項目       | 内容                       |
| ---------- | -------------------------- |
| ①説明      | 無線機メーカーを選択する。 |
| ②種別      | セレクトボックス           |
| ③表示/入力 | 入力                       |
| ④表示条件  | 常時                       |

⑤制御条件

- なし

### 2.2 機種

| 項目       | 内容                     |
| ---------- | ------------------------ |
| ①説明      | 無線機の機種を選択する。 |
| ②種別      | セレクトボックス         |
| ③表示/入力 | 入力                     |
| ④表示条件  | 常時                     |

⑤制御条件

- 選択中のメーカーに対応する機種一覧を表示する。機種一覧は、無線機定義ファイル（`transceiver.json`）の内容による。
  - ICOM: IC-9100、IC-9700、IC-910、ID-52
  - YAESU: FT-991 / FT-991A、FT-897 / FT-897D

| ④表示条件  | 常時                                     |

### 2.5 CI-Vアドレス

| 項目       | 内容                                        |
| ---------- | ------------------------------------------- |
| ①説明      | ICOMのCI-Vアドレスを入力する（最大2文字）。 |
| ②種別      | テキストボックス                            |
| ③表示/入力 | 入力                                        |
| ④表示条件  | メーカーがICOMの場合のみ表示する。          |

⑤制御条件

- なし（メーカーがICOM以外の場合は、項目ごと表示しない）。

### 2.6 ボーレート

| 項目       | 内容                                 |
| ---------- | ------------------------------------ |
| ①説明      | シリアル通信のボーレートを選択する。 |
| ②種別      | セレクトボックス                     |
| ③表示/入力 | 入力                                 |
| ④表示条件  | 常時                                 |

⑤制御条件

- なし

### 2.7 機種別の案内

| 項目       | 内容                                                                            |
| ---------- | ------------------------------------------------------------------------------- |
| ①説明      | 選択中の機種について、無線機側のメニュー設定などの案内を表示する。              |
| ②種別      | ラベル（複数行のテキスト）                                                      |
| ③表示/入力 | 表示                                                                            |
| ④表示条件  | YAESUのFT-991 / FT-991A、またはFT-897 / FT-897Dを選択している場合のみ表示する。 |

⑤制御条件

- FT-991 / FT-991A: メニュー「031 CAT RATE」（RS-232Cケーブルを使用する場合は「029 232C RATE」）を、ボーレートと同じ値にする旨を表示する。
- FT-897 / FT-897D: メニュー「001 EXT MENU」を「ON」、「020 CAT/LIN/TUN」を「CAT」にし、「019 CAT RATE」をボーレートと同じ値にする旨、USB-D / LSB-D（DIG）の側波帯がメニュー「038 DIG MODE」で決まる旨、FM-D（PKT）の速度がメニュー「073 PKT RATE」で決まる旨、運用中にVFOを切り替えない旨を表示する。

### 2.8 接続テストボタン

| 項目       | 内容                                         |
| ---------- | -------------------------------------------- |
| ①説明      | 現在の設定で無線機への接続テストを実行する。 |
| ②種別      | ボタン                                       |
| ③表示/入力 | 入力                                         |
| ④表示条件  | 常時                                         |

⑤制御条件

- メーカー・機種・シリアルポートがすべて選択されている場合のみ有効。
- テスト実行中はローディング表示し、再クリック不可。
- シリアルポートは、選択中の機種に応じたストップビットで開く（無線機定義ファイルの`stopBits`。YAESUのFT-991 / FT-897は2、それ以外は1）。

## 3. イベント

### 3.1 接続設定タブ操作イベント

| No  | 対象項目           | イベント | 動作                                                                                         |
| --- | ------------------ | -------- | -------------------------------------------------------------------------------------------- |
| 1   | メーカー           | 値変更   | 機種リストを更新する。ICOM以外の場合はCI-Vアドレスを空にする（CI-Vアドレスの項目は非表示）。 |
| 2   | 機種               | 値変更   | ICOMの場合、選択機種のデフォルトCI-Vアドレスを設定する。機種別の案内の表示を切り替える。     |
| 3   | シリアルポート更新 | クリック | シリアルポート一覧を最新情報に更新する。                                                     |
| 4   | 接続テストボタン   | クリック | 選択設定で接続テストを実行し、成功/失敗を通知する。                                          |
